How ranked-choice voting works

In a ranked-choice vote, each voter puts the choices in order: first, second, third. The count then finds a winner that most voters can accept. Another name for the most common form is instant-runoff voting. This guide explains it in plain steps, with an example.

The problem with picking one choice

In a normal vote, each person picks one option, and the option with the most votes wins. This can go wrong when similar options split the vote. Twelve people vote for a class party menu. Five pick pizza, four pick pasta and three pick tacos. Pizza wins with 5 of 12 votes. Yet seven people did not pick pizza. If the three taco voters had been asked for a second choice, the result might change.

A voter also has to guess. A person who likes tacos best may vote for pasta instead, to avoid "wasting" a vote. A ranked ballot removes this problem. The voter can be honest, because a vote moves on when the first choice cannot win.

How instant runoff works, step by step

  1. Rank. Each voter ranks the choices. 1 is the favourite, 2 is the next, and so on. A voter may rank only some of the choices.
  2. Count first choices. Every ballot counts for its first choice.
  3. Look for a majority. If one choice has more than half of the counted votes, it wins. The count ends.
  4. Remove the last choice. If nobody has a majority, the choice with the fewest votes is out.
  5. Move the votes. Each ballot that had the removed choice first now counts for its next choice that is still in the count.
  6. Repeat. Go back to step 3 until one choice has more than half.

A worked example

Twelve voters rank three options. Five voters rank Pizza first. Four rank Pasta first. Three rank Tacos first, and all three rank Pasta second.

RoundPizzaPastaTacosWhat happens
1543Nobody has more than 6. Tacos has the fewest, so Tacos is out.
257outThe three taco votes move to Pasta. Pasta has 7 of 12 and wins.

Pizza had the most first-choice votes, but Pasta wins. Seven of the twelve voters prefer Pasta to Pizza, so Pasta is the choice that most of the group can accept.

Run a class vote in five minutes

Quick Vote runs the count for you, and shows each round, so that you can put it on the board.

  1. Open Quick Vote and click Make a single-booth poll.
  2. Type the question. Add two to twelve choices. A picture for each choice helps younger children.
  3. Choose a password to close voting. Keep it from the class.
  4. Pass the device around. Each child taps the choices in order, then presses Cast my vote.
  5. When everyone has voted, press Close voting and show the result and type the password.
  6. Walk through the rounds with the class.

Make a poll

Several classes, rooms or sites can vote on the same question, each on its own device. Quick Vote adds up all the booths. See the setup guide for a multi-booth poll.

Tips for teachers and organisers

  • Run a show of hands first. Then run the ranked vote and compare the two results. The difference makes a good talking point.
  • Ask voters to rank at least three choices, if there are that many. A ballot with one choice stops counting when that choice is out.
  • Use pictures for young children. A choice with no picture shows only its name.
  • Keep the password to close voting private, so that the result shows only when you are ready.

Questions

What if a voter ranks only one choice?

That ballot counts for the choice while it is in the count. When the choice is out, the ballot has no next choice, so it stops counting. This is normal. It is why ranking more choices gives a voter more say.

What if two choices tie?

If two choices tie for the fewest votes, Quick Vote looks at the earlier rounds to decide which one is out. If every earlier round is equal, the choice that is last in the list is out. If all the remaining choices tie, the result is a tie.

Is ranked-choice voting used in real elections?

Yes. For example, Ireland elects its president this way. Australia's House of Representatives uses a form of it, and some places in the United States use it too.

Does the first-choice winner always win?

No. A choice with a majority of first-choice votes always wins. Without a majority, the later rounds can change the result, as in the example above.
