What is Quick Vote?

Quick Vote is a free web app that lets a group choose between options fairly. Each voter ranks the options in order. The app then counts the votes with instant-runoff voting, and shows each round of the count, so everyone can see how the winner came about.

Teachers use it for class votes: a project topic, a field trip or a party menu. Clubs, teams and youth groups use it to choose a name, a date or a prize. There is nothing to install and no account to make. The tap-to-rank screen is simple enough for young voters, and the booth host stays in control.

How ranked-choice (instant runoff) voting works

  1. Each voter ranks the choices: 1 for the favourite, then 2, then 3.
  2. The app counts every voter's first choice.
  3. If one choice has more than half of the votes, it wins.
  4. If not, the choice with the fewest votes is out. Its voters' votes move to their next choice.
  5. The app repeats until one choice has more than half.

Because a vote moves to the next choice, similar options do not split the vote, and a voter never has to guess a "safe" choice. Read the full guide with a worked example.

One device, or many

A single-booth poll runs on one device, such as a classroom tablet or a laptop. Nothing leaves the device, and it works with no network after the page loads. The person who makes the poll sets a password to close voting and show the result.

A multi-booth poll lets many groups vote at the same time, each on its own device. A voting centre that you set up (a free Cloudflare account is usually enough) adds up all the votes. A group with a weak signal can vote offline. The booth sends its votes when the signal returns. A group that cannot use a device can count hands, and a host enters the totals.

Privacy

A ballot holds only the ranking, the group name and a random booth ID. It holds no voter name and no time of day. Quick Vote has no accounts and no tracking. A single-booth poll never sends anything to a server.

Questions

Do voters need an account?

No. A voter taps the choices in order and presses "Cast my vote". The booth host runs the device.

Does it work with no internet?

A single-booth poll works with no network once the page has loaded. A multi-booth booth needs a signal when the host first opens it. After that, it saves votes on the device and sends them when the signal returns.

Is it free?

Yes. Quick Vote is open source. A multi-booth poll needs a voting centre that you run on Cloudflare. The free plan is usually enough for classes and clubs.

Can I add pictures?

Yes. A choice can have a photo, or only a name. A choice with no photo shows only its name.

What if two choices tie?

If two choices tie for the fewest votes, the count looks at the earlier rounds to decide which one is out. If every earlier round is equal, the choice that is last in the list is out. If all the remaining choices tie, the result is a tie. The round-by-round view shows each step.

Where is the code?

The code is on GitHub. The repository has a guide to set up your own voting centre, and a guide for people who want to contribute.
